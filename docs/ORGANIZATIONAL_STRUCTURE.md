# الهيكل التنظيمي المقترح لمشروع أطلس ليبيا السياحي

## المستوى الإشرافي
- وزير السياحة والصناعات التقليدية: الاعتماد والتوجيه العام.
- اللجنة التوجيهية العليا: حسم النطاق والأولويات والتكامل المؤسسي.
- مركز المعلومات والتوثيق السياحي: مالك المشروع والبيانات والمنصة.

## الإدارة التنفيذية
- مدير عام المركز / الراعي التنفيذي.
- مدير مشروع الأطلس.
- مكتب إدارة المشروع PMO والمتابعة والتقارير.

## فرق العمل
1. **فريق البيانات والتوثيق:** السجل، التصنيفات، الأكواد، المصادر، والميتاداتا.
2. **فريق GIS والمسح المكاني:** الإحداثيات، الطبقات، الحدود، والتحقق المكاني.
3. **فريق المحتوى والصور:** النصوص، الصور الحقيقية، حقوق الاستخدام، واللغات.
4. **فريق المنصة والتكامل:** Frontend، Backend، API، PostGIS، GitHub، وVisit Libya.
5. **فريق الجودة والاعتماد:** قواعد الجودة، إزالة التكرار، المراجعة المرحلية، وسجل التدقيق.
6. **فريق الأمن والاستمرارية:** الصلاحيات، النسخ الاحتياطي، حماية البيانات، والتعافي.
7. **فريق الترويج والشراكات:** العرض المؤسسي، المستثمرون، البلديات، والجهات المزودة للبيانات.

## RACI مختصر لنسخة العرض
- اعتماد شكل العرض: الراعي التنفيذي A، مدير المشروع R.
- توفير KML والصور: فريق البيانات R، GIS C.
- بناء الواجهة الثابتة: فريق المنصة R.
- فحص التشغيل قبل الاجتماع: الجودة R، مدير المشروع A.
- النشر المؤقت أو الداخلي: المنصة R، الأمن C، الراعي A.
