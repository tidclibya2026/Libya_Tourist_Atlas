# حزم الإجراءات المؤسسية — المرحلة الثانية

توزع الملفات حسب الجهة المطلوبة للاستكمال، ولا تعني أن الجهة مصدر للبيانات الحالية. تعبئ الجهة نموذج الرد مع مرجع وثيقة أو سجل رسمي وتاريخ التحقق واسم الموظف وحالة الاعتماد. الأدلة المقبولة: وثيقة رسمية، قيد سجل، مخطط معتمد، ترخيص، أو إفادة مكتوبة من جهة مخولة. يعاد الملف إلى مركز المعلومات والتوثيق السياحي، ويتولى فريق تكامل البيانات مراجعة الأدلة والدمج. يوصى بتحديث P1 فورًا، وP2 في دورة ربع سنوية، وP3 نصف سنويًا. لا يعتمد أي تغيير بلا مرجع قابل للتتبع.
