# تعليمات نموذج رد الجهات

يجب الاحتفاظ بـ`action_id` و`feature_id` دون تغيير، وتعبئة القيم التي تم التحقق منها فقط. يرفق مرجع الوثيقة وتاريخ التحقق والموظف المخول. تترك الحقول غير المتحققة فارغة، ولا تستخدم كلمة «لا» للتعبير عن غياب البيانات. حالات الاعتماد المقترحة: approved، rejected، needs_more_evidence.
