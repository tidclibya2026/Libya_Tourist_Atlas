# خطة وسائط السجل الوطني

لم تُنفذ استعادة تلقائية على `national-atlas.kml` ضمن هذه المهمة.

الخطة المقترحة المنفصلة:

1. تشغيل جرد read-only للروابط الخارجية والمحلية مع تجميعها حسب المضيف والحالة.
2. معالجة دفعات محدودة قابلة للاستئناف، مع سجل master مستقل وميزانية زمن/حجم واضحة.
3. تطبيق شروط القبول نفسها: HTTP 200، `image/*`، magic bytes صحيحة، حجم أكبر من 1KB، وفك ترميز Pillow/المتصفح.
4. إزالة الروابط الفاشلة من gallery فقط بعد حفظها في تقرير missing media، والإبقاء على `source_media_url` للأثر التدقيقي.
5. اختبار عينة طبقية قبل أي تعميم، ثم مراجعة بشرية قبل تعديل ملف KML النهائي.

لا يبدأ التنفيذ إلا بموافقة صريحة منفصلة بسبب حجم الطبقة الوطنية.
