# LSTA Presentation Static
نسخة عرض ثابتة لمشروع أطلس ليبيا السياحي، منفصلة تمامًا عن منصة lsta.ly التشغيلية.

## التشغيل
لا تفتح `index.html` بالنقر المباشر لأن المتصفح قد يمنع قراءة KML. شغّل Web Server محليًا:

```bash
python -m http.server 8080
```
ثم افتح `http://localhost:8080`.

## النشر
يمكن رفع المجلد كما هو إلى GitHub Pages أو Netlify أو أي استضافة Static.

## الملاحظات
- الصور تُقرأ من وصف KML وقد تعتمد على روابط Google الخارجية.
- طبقة الموارد الطبيعية مرتبطة مباشرة بملف GeoJSON على GitHub.
- طبقة السجل الوطني كبيرة، لذلك لا تُحمّل تلقائيًا.
